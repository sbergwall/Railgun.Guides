# Proxmox Configure 

This will help to configure a Proxmox host after installation is done.

## Add disks

[https://www.thewantricks.com/2025/03/how-to-add-disk-to-proxmox-step-by-step.html](https://www.thewantricks.com/2025/03/how-to-add-disk-to-proxmox-step-by-step.html)

lsblk

Datacenter > PVE1 > Shell:
mkdir /mnt/ssd
mount /dev/sda1 /mnt/ssd

To make the mount persistent across reboots, add it to /etc/fstab:
echo '/dev/sda1 /mnt/ssd ext4 defaults 0 0' >> /etc/fstab

In the Proxmox web interface, select your node, then go to "Datacenter" > "Storage."

Add the Disk as Storage:
Click "Add" and choose the type of storage you want to create (e.g., "Directory," "LVM," or "ZFS").
For a simple setup, select "Directory" and provide the following details:
* ID: A unique name for the storage (e.g., ssd).
* Directory: The mount point for the disk (e.g., /mnt/ssd).
* Content: Choose what the storage will be used for (e.g., "Disk Image," "ISO," "Container").
* Click "Add" to save the configuration.
