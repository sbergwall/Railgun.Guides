# Proxmox Configure 

This will help to configure a Proxmox host after installation is done.

## Add disks

[https://www.thewantricks.com/2025/03/how-to-add-disk-to-proxmox-step-by-step.html](https://www.thewantricks.com/2025/03/how-to-add-disk-to-proxmox-step-by-step.html)

https://www.youtube.com/watch?v=HqOGeqT-SCA

proxmox host > Disks > mark your disk > Wipe Disk > mark you disk > Initialize Disk with GPT

proxmox host > Disks > Directory > Create: Directory >
 * Disk: /dev/sda
 * Fiesystem: ext4
 * Name: ssd
	> Create 

### Add ISO 

Windows Server:
Select Proxmox host > newly added storage > ISO Images > Download from URL > https://go.microsoft.com/fwlink/?linkid=2345730&clcid=0x409&culture=en-us&country=us

VirtIO:
Select Proxmox host > newly added storage > ISO Images > Download from URL > https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/stable-virtio/virtio-win.iso
